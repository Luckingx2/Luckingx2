# 🤖 인스타그램 자동 발행 가이드 (Meta Graph API)

`publish_instagram.py`로 카드 10장을 **캐러셀 1게시물**로 코드 발행합니다.
딱 **2가지**만 준비되면 끝납니다.

---

## ✅ 준비 1 — 이미지를 '공개 URL'로
인스타 API는 **공개 https 이미지 URL**만 받습니다(비공개 저장소 ❌). 둘 중 하나:

**(A) 가장 쉬움 — 저장소를 Public 전환 후 jsDelivr CDN**
1. GitHub 저장소 → Settings → General → 맨 아래 *Change visibility* → **Public**
2. `IMAGE_BASE_URL` 에 아래 형식 사용(`<SHA>` = 카드가 든 커밋 해시):
   ```
   https://cdn.jsdelivr.net/gh/Luckingx2/Luckingx2@<SHA>/card-news/cards
   ```

**(B) 비공개 유지 — GitHub Pages / S3 등 정적 호스팅**
- `card-news/cards/` 의 PNG를 호스팅하고 그 폴더 URL을 `IMAGE_BASE_URL` 에 입력
  (예: `https://<id>.github.io/<repo>/card-news/cards`)

> 점검: `python3 publish_instagram.py --dry-run` → 10장이 모두 ✅면 통과.

---

## ✅ 준비 2 — Graph API 자격 2개 (IG_USER_ID, 토큰)
1. 인스타를 **프로페셔널(비즈니스/크리에이터)** 계정으로 전환하고 **페이스북 페이지**와 연결
2. https://developers.facebook.com → 앱 만들기(비즈니스) → 제품에 **Instagram Graph API** 추가
3. **Graph API 탐색기**에서 권한 부여 후 단기 토큰 발급
   - 권한: `instagram_basic`, `instagram_content_publish`, `pages_read_engagement`, `business_management`
4. 단기 토큰 → **장기 토큰(60일)** 으로 교환:
   ```
   GET https://graph.facebook.com/v21.0/oauth/access_token
     ?grant_type=fb_exchange_token&client_id=<APP_ID>
     &client_secret=<APP_SECRET>&fb_exchange_token=<SHORT_TOKEN>
   ```
5. **IG_USER_ID** 조회(연결된 페이지에서):
   ```
   GET https://graph.facebook.com/v21.0/<PAGE_ID>?fields=instagram_business_account&access_token=<TOKEN>
   ```

## ▶️ 실행
```bash
cd card-news
pip install requests python-dotenv
cp .env.example .env          # IG_USER_ID / IG_ACCESS_TOKEN / IMAGE_BASE_URL 채우기
python3 publish_instagram.py --dry-run   # URL 점검
python3 publish_instagram.py             # 발행!
```
캡션은 `caption.txt` 를 수정하면 그대로 반영됩니다.

## 🔐 보안 주의
- `.env`(토큰)는 **절대 커밋 금지** (이미 `.gitignore` 등록). 채팅·캡처로도 공유 마세요.
- 토큰이 노출되면 즉시 Meta에서 **재발급/폐기** 하세요.
- 자동 발행은 24시간 내 **계정당 게시 횟수 제한(약 50건)** 이 있습니다.

> 막히는 단계(토큰 교환, IG_USER_ID 조회 등)를 알려주시면 그 부분을 같이 풀어드릴게요.
> 단, 토큰 값 자체는 채팅에 붙여넣지 마시고 `.env`에만 넣어주세요.
