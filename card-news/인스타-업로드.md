> 카드 이미지(`cards/card-01~10.png`)를 인스타 **캐러셀 1개 게시물**로 올리는 패키지입니다.

## 1️⃣ 계정 만들기 (직접, 약 5분)
1. 인스타그램 앱 → 가입 → 휴대폰/이메일 인증
2. **추천 계정명(아이디)**: `money.firststep` / `jaeteche_firststep` / `wolgeup.diary`
3. 프로필 세팅
   - 이름: `재테크 첫걸음 | 사회초년생 돈 공부`
   - 카테고리: **개인 블로그** 또는 **교육**
   - 소개글 ↓
     ```
     💰 월급은 들어오는데 왜 안 모이지?
     🎓 대학생도 이해하는 가장 쉬운 재테크
     📌 매주 1장씩 돈 공부 카드뉴스
     ⚠️ 투자 권유 아님 · 정보 제공용
     ```
4. (선택) **프로페셔널 계정**으로 전환 → 인사이트·예약발행·자동업로드 가능

## 3️⃣ (선택) 자동 업로드까지 원하시면 — Meta Graph API
직접 안 올리고 코드로 발행하려면 아래가 필요합니다. 준비되면 발행 스크립트를 만들어 드릴게요.
1. 인스타 **프로페셔널(비즈니스) 계정** + **페이스북 페이지** 연결
2. [Meta for Developers](https://developers.facebook.com)에서 앱 생성 → **Instagram Graph API** 권한
3. 발급물 3가지: `IG_USER_ID`, `LONG_LIVED_ACCESS_TOKEN`, 그리고 이미지가 올라간 **공개 URL**
   - (캐러셀은 각 이미지를 공개 URL로 올린 뒤 → 컨테이너 생성 → 발행)
4. 위 3개를 알려주시면 `publish_instagram.py`를 만들어 자동 발행해 드립니다.

> ※ API 발행은 이미지가 인터넷에 공개 URL로 있어야 합니다(예: GitHub Pages, S3 등).
> GitHub Pages로 카드 이미지를 호스팅하는 것까지 제가 세팅해 드릴 수 있어요.
