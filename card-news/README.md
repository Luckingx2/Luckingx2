# 💰 초보 직장인 재테크 카드뉴스 (2026)

사회초년생·재테크 초보를 위한 **가장 쉬운 재테크 상식** 카드뉴스 10장입니다.
요즘 트렌드(2026년 6월 출시 **청년형 ISA·청년미래적금**)를 집중적으로 다뤘고,
대학생에게 설명하듯 쉽게, 그림(SVG 코인·도넛/막대 차트·번호 스텝·비교표)을 많이 넣었습니다.

## 📦 구성
| 파일 | 설명 |
|------|------|
| `cards/card-01.png ~ card-10.png` | ⭐ **바로 쓰는 카드 이미지 10장** (1080×1080) |
| `재테크-카드뉴스.pdf` | 10장을 한 번에 넘겨보는 PDF |
| `index.html` | 원본(브라우저용, 이모지 포함 풀버전) |
| `원고-카드뉴스.md` | 전체 텍스트 원고 (Canva·미리캔버스 복붙용) |
| `build.py` | HTML → PDF → PNG 자동 변환 스크립트 |

1. 표지 — "월급은 들어오는데 왜 안 모이지?"
2. 통장 쪼개기 (3개 통장)

5. 일찍 시작의 힘 (25세 vs 35세)
6. 🔥 청년형 ISA (절세 만능통장)
7. 🎁 청년미래적금 (6/22 출시, 정부 지원)
8. ISA vs 청년미래적금 비교
9. 연금저축·IRP 세액공제 (13월의 월급)
10. 마무리 — 3단계 실천 로드맵

## ▶️ 바로 쓰기
`cards/` 폴더의 PNG를 그대로 인스타·블로그에 올리거나, `재테크-카드뉴스.pdf`로 넘겨보세요.

## 🛠️ 다시 빌드하기 (내용 수정 후)
```bash
cd card-news
pip install weasyprint pymupdf      # 최초 1회
python3 build.py                    # 폰트 자동 다운로드 → PDF + cards/*.png 생성
```
- `index.html`을 수정한 뒤 `build.py`를 실행하면 PNG/PDF가 갱신됩니다.
- 한글 폰트(Black Han Sans·Jua·Noto Sans KR)는 `build.py`가 `fonts/`에 자동 내려받습니다.
- 인쇄본(PDF/PNG)은 일부 환경의 컬러 이모지 렌더 이슈를 피하려고 이모지를 빼고
  SVG·번호·차트로 대체합니다. 이모지 포함 풀버전은 `index.html`에서 볼 수 있습니다.
