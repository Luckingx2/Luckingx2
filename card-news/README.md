# 💰 초보 직장인 재테크 카드뉴스 (2026)

사회초년생·재테크 초보를 위한 **가장 쉬운 재테크 상식** 카드뉴스 세트입니다.
요즘 트렌드(2026년 6월 출시 **청년형 ISA·청년미래적금**)를 집중적으로 다뤘고,
대학생에게 설명하듯 쉽게, 그림(SVG·이모지·차트)을 많이 넣었습니다.

## 📦 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 카드뉴스 10장 본체 (브라우저로 열면 바로 보임, 카드당 1080×1080) |
| `원고-카드뉴스.md` | 모든 카드 텍스트 원고 (Canva·미리캔버스에 복붙용) |
| `render.mjs` | 카드를 PNG 이미지로 자동 추출하는 스크립트 (선택) |

## 🃏 카드 목차 (10장)
1. 표지 — "월급은 들어오는데 왜 안 모이지?"
2. 통장 쪼개기 (3개 통장)
3. 선저축 후지출 (50:30:20 황금비율)
4. 복리의 마법 & 72의 법칙
5. 일찍 시작의 힘 (25세 vs 35세)
6. 🔥 청년형 ISA (절세 만능통장)
7. 🎁 청년미래적금 (6/22 출시, 정부 지원)
8. ISA vs 청년미래적금 비교
9. 연금저축·IRP 세액공제 (13월의 월급)
10. 마무리 — 3단계 실천 로드맵

## ▶️ 보는 법
```bash
# 그냥 브라우저로 index.html 열기 (더블클릭)
# 각 카드를 캡처해서 인스타·블로그에 올리면 끝!
```

## 🖼️ PNG로 뽑고 싶다면 (브라우저가 있는 PC에서)
```bash
cd card-news
npm install playwright
npx playwright install chromium
node render.mjs      # → cards/card-01.png ~ card-10.png 생성
```
